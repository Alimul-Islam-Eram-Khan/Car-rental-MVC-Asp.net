# 🚗 Dream Car — ASP.NET MVC Project

Dream Car is a full‑stack **ASP.NET MVC** application built with **C#** in **Visual Studio**.  
It provides a marketplace where buyers can browse car models, compare prices, book vehicles, and communicate with sellers. Sellers can list cars, manage inventory, and respond to inquiries.

---

## ✨ Features

### For Buyers
- Browse cars by make, model, year, and price.
- View detailed model pages with specs, images, and pricing.
- Compare multiple models side‑by‑side.
- Book or reserve cars online.
- Message sellers directly (email notifications included).
- Save favorite models for later.

### For Sellers
- Create and manage car listings with images and details.
- Maintain inventory (active, reserved, sold).
- Receive and respond to buyer inquiries.
- Get email alerts for new bookings or messages.

### Admin (optional)
- Manage users (buyers/sellers).
- Moderate listings and reported content.
- Configure system settings.

---

## 🧱 Tech Stack
- **Backend:** ASP.NET MVC 5 (C#), Entity Framework  
- **Frontend:** Razor Views, Bootstrap, jQuery  
- **Database:** SQL Server / LocalDB  
- **Authentication:** ASP.NET Identity (roles: Buyer, Seller, Admin)  
- **Email:** SMTP integration for notifications
